# GameDev PP — аналитическая платформа для разработчиков видеоигр

## 1. Цель проекта
Помочь независимым разработчикам принимать решения на основе анализа рынка: выбор жанра, платформы, времени релиза.

## 2. Роли пользователей
- **Гость**: один бесплатный анализ за сессию
- **Зарегистрированный пользователь**: неограниченные анализы.

## 3. Модели данных
- **Genre**: name, slug, rawg_id
- **Platform**: name, slug, rawg_id  
- **Game**: title, release_date, rating, metacritic, genres (M2M), platforms (M2M), rawg_id

## 4. Ключевой функционал
* Выбор жанров и временного периода → запрос к RAWG API
* Анализ трендов: динамика релизов, средний рейтинг
* Визуализация: графики через Plotly
* Рекомендации: "Жанр растёт", "Конкуренция высока" и т.д.
* Ограничение гостей: 1 анализ за сессию

## 5. Внешние интеграции / Аналитика
- **API**: RAWG Video Games Database (https://rawg.io/apidocs)
- **Аналитика**: Pandas (агрегация), Plotly (графики)
