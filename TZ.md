# PP

## 1. Цель проекта
Помочь независимым разработчикам видеоигр принимать обоснованные решения на этапе проектирования: выбор перспективного жанра, определение целевых платформ, подбор оптимального времени релиза на основе анализа рыночных данных.

## 2. Роли пользователей
- **Гость**: может выполнить один анализ без регистрации
- **Зарегистрированный разработчик**: сохраняет историю запросов, получает расширенную аналитику

## 3. Модели данных
- **Genre**: name (str), slug (str), rawg_id (int)
- **Platform**: name (str), slug (str), rawg_id (int)  
- **Game**: title (str), release_date (date), rating (float), metacritic (int), genres (M2M), platforms (M2M), rawg_id (int)

## 4. Ключевой функционал
* Пользователь выбирает 1-3 жанра и диапазон лет (2018-2025)
* Система получает данные из RAWG API и сохраняет в БД
* Платформа строит графики: количество релизов по годам, средний рейтинг по жанрам
* Система даёт рекомендации: "Жанр X растёт, но рейтинг падает — осторожно, перенасыщение"

## 5. Внешние интеграции / Аналитика
- **API**: RAWG Video Games Database (https://rawg.io/apidocs)
- **Аналитика**: Pandas (агрегация данных), Plotly (визуализация трендов)
